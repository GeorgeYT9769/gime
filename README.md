# Gime

A small desktop app for backing up game save files with **Git**.

Open it, pick a game, see your local version vs the uploaded version, then
Pull or Push. The list of games, their paths and commit message patterns are
remembered between sessions.

## Requirements

- **Python 3.10+** with Tkinter (the standard `python.org` Windows installer
  includes it)
- **Git** on your `PATH` (<https://git-scm.com/download/win>)

No third-party packages are needed — the app is pure standard library.

## Run

```
python gime.py
```

## What it does

| Feature | Where |
| --- | --- |
| Remembers your games | stored in `gime.json` next to `gime.py` |
| Add games with a custom name + path | **Add…** button, or the *Games* menu |
| Detects `.git` | shown under **Versions**; offers **Initialize Git…** if absent |
| Custom commit message patterns | pattern field in the Add/Edit dialog, **Tokens ▾** menu |
| Mine vs uploaded version | **Versions** panel — refreshed after every action |
| Pull / Push | the four action buttons |
| See git's own output | the **Output** panel at the bottom |
| Light / dark mode | *View ▾ Dark mode*, or the button in the status bar |
| Git version + game count | the status bar along the bottom |

### Versions panel

- **Mine (local)** — the last commit in this folder: short hash, date, subject.
- **Uploaded (remote)** — the last commit on the tracked remote branch.
- **Status** — `in sync`, `mine is 2 ahead`, `uploaded is 3 ahead`, or
  `diverged`. Highlighted in the theme's success / warning / error colour.
- **Remote** — the `origin` URL; **Set remote…** points it at your repository.

A quiet `git fetch --prune` runs whenever you select a game or press
**Refresh**, so *Uploaded* really is what is on the server, not what was
fetched last week. Failures are silent unless you pressed **Refresh**.

### Commit message patterns

The Add/Edit dialog takes a pattern; it is expanded into the actual message
whenever you select a game. **Regenerate** re-expands it, and you can edit the
message by hand before committing (a hand-written message is never overwritten
by a refresh).

| Token | Example |
| --- | --- |
| `{datetime}` | `2026-10-06 14:32:05` |
| `{datetime:%Y%m%d-%H%M%S}` | `20261006-143205` |
| `{date}` | `2026-10-06` |
| `{date:%d.%m.%Y}` | `06.10.2026` |
| `{time}` | `14:32:05` |
| `{game}` | `Elden Ring` |
| `{count}` | `3` |
| `{files}` | `save00.dat, save01.dat (+1 more)` |
| `{branch}` | `main` |
| `{host}` | `DESKTOP-ABC` |
| `{user}` | `juraj` |
| `{path}` | `D:/Games/ELDEN RING` |

Default pattern:

```
{datetime}: {game} save ({count} file(s))
```

Leave the field blank on a game to use the app-wide default. Unknown tokens
are left untouched rather than raising an error.

### Commit before push

On by default. Push will first run `git add -A` + `git commit` with the
message shown in the commit message field, so a Push from a clean slate always
works. Uncheck it to push only what you have already committed.

### Look and feel

- **Dark mode** — *View ▾ Dark mode* in the menu bar, or the button on the
  right of the status bar. The choice is stored in `gime.json` (`"theme"`)
  and restored on the next run. Both palettes live in `gime_theme.py`.
- **Status bar** — how many games are configured and which Git you are
  running (`git version 2.53.0`), so a broken install is obvious at a glance.
- **App icon** — `gime.png` (used via `iconphoto`, every platform) and
  `gime.ico` (used via `iconbitmap` on Windows, for the taskbar). Both are
  generated by `python make_icon.py`, which draws a git-branch mark on an
  indigo-to-cyan rounded square in pure Python — no Pillow required.

### Pull safety

Pull runs as `git pull --rebase --autostash`, so uncommitted save files (a
game still running) are set aside and put back afterwards. If the rebase hits
a conflict, Gime aborts it and restores the pre-pull state instead of leaving
you stranded mid-rebase — it tells you in the Output panel.

## Files

```
gime.py           Tkinter UI — entry point
gime_core.py      git plumbing, repo inspection, patterns, game storage
gime_theme.py     light/dark palettes and ttk styling
make_icon.py      regenerates gime.png and gime.ico
gime.png/.ico     the application icon
gime.json         created on first run: your games and settings
test_gime_core.py tests for the git/storage logic
test_gime_ui.py   display-less tests that drive the real UI code
```

## Tests

```
python -m unittest discover -v
```

`test_gime_ui.py` runs without a display: it substitutes a stub `tkinter`
and drives the real `App` methods against real temporary git repositories,
including a full push/pull round trip between two "machines", the dark-mode
toggle, and the status bar.

## Notes

- `gime.json` is plain JSON — safe to edit by hand.
- Removing a game only removes it from the list; no files are touched.
- Authentication is left to Git itself (Git Credential Manager pops up for
  HTTPS remotes). `GIT_TERMINAL_PROMPT` is forced to `0` so the app can never
  hang waiting for a password nobody can type.
